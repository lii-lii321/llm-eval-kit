# 复现：Student (1908) 配对 t 检验

- 论文：Student. "The Probable Error of a Mean." Biometrika 6(1), 1908.
- 数据：Cushny & Peebles (1905) 催眠剂实验——10 名患者、権眠剂 B 相对对照的额外睡眠时长差值（小时）。该数据后被 Fisher (1925)《研究工作者的统计方法》采用，成为配对 t 检验的教科书示例。
- 复现目标：论文示例中的 t 统计量（t ≈ 4.06, df = 9）。

## 运行

```bash
python run.py
```

依赖：scipy。数据以内嵌数组形式给出（n=10，无需下载）。

## 结果对照

| 来源 | 统计量 |
|---|---|
| Student (1908) 论文 | t ≈ 4.06（df = 9，单尾参考） |
| 本次复现（scipy ttest_1samp，双侧） | t = 4.0621，p = 0.00283 |

## 偏差说明

- 论文时代没有现代双侧 p 值约定：Student 给出的是单尾参考值（量级 ≈ 0.0005–0.001）；
  双侧 p = 0.00283 与之完全一致。
- 原文按"样本均值的可能误差"表述，与现代 t 统计量定义等价。
